Git Together lesson text uses a "relatable, you-centered" voice: open from the learner's own experience ("You've probably done this..."), then show how Git fixes it. Natural, full sentences with an occasional short one ("Names lie.").

**Why:** On 2026-10-01 the user said my first lesson 1 draft felt "dummy and weird". It was too choppy, too cutesy ("Much better", "Funny thing"), restated the screen in done messages, and used vague lines like "Git is watching". They picked this voice out of three samples.
**How to apply:** Done messages add meaning instead of describing what the screen already shows. Don't stack fragments. Still follow [[writing-style-rules]] (no dashes, colons, or semicolons). Polish one lesson fully before moving on.
