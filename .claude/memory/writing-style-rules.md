When writing prose for the user (docs, tutorial copy, lesson text):
- Active voice, address the reader as "you", short plain words, conversational, definitive statements (no "might").
- NO dash characters at all: no hyphens in compound words (write "step by step", "non developers"), no en or em dashes.
- No colons, semicolons, asterisks, emojis, hashtags, clichés, jargon, marketing language.
- No AI filler ("it's important to note", "streamline", "game changer", "not just X but Y", "let's explore").
- Mix short and long sentences.

**Why:** User pasted these as explicit writing rules on 2026-10-01 while drafting a git tutorial curriculum.
**How to apply:** Apply to all user-facing written content. Markdown syntax (list markers, table separators) is fine, but rendered text must follow the rules. Related: [[prefers-generated-over-handwritten]]
