About Git Explained

Git Explained is a free course for people who need to use Git but don't write code, or are only starting to. It teaches the ideas behind Git by letting you do them in the browser.

There's nothing to install and no account to create.

How a lesson works

Short

Each lesson takes about five minutes and has a few short steps. Stop after any step and pick up where you left off.

Hands on

Every step gives you one task. You press the button it asks for and watch which files move, and where to.

Plain words first

Places and actions use everyday names, with the Git term beside each one. The glossary lists them all.

What it leaves out

Typing Git commands, setting Git up on your computer, and advanced topics such as rebasing. When you're ready for those, the official Git documentation picks up where this course stops.

Questions

Do I need a GitHub account?

Not for the lessons. From lesson 5 on, the exercise shows GitHub, so you see how it works before you sign up.

Is my progress saved?

Yes, in this browser. Come back on the same device and you see which lessons you started and which ones you finished.

Does it cost anything?

No. The whole course is free.

Open source, and yours to share

Git Explained is open source. The lessons, the exercises, and this site all live in one public repository on GitHub. Anyone can read how it works, suggest a change, or fix a mistake.

Star the repository

Stars are how other people find projects on GitHub. One click helps the next person who's stuck on Git.

Tell someone

Send it to a colleague who just joined a GitHub project, or to anyone who has said Git isn't for them.

Suggest a change

Spotted a mistake or a confusing step? Open an issue or a pull request. The glossary explains both.
