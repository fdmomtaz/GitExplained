1Git Together: "Making changes & staging" lesson
Assumptions. Absolute beginners, many of them non-developers. Git is taught as four places: working files, staging, local history and origin on GitHub. Their names come from a switchable metaphor (Tweaks → Metaphor): plain git terms, photo, shipping or desk. The example project is a shared recipe book instead of code. Learners complete each step by pressing the concept button it asks for. Next stays locked until they do.
Layout. Follows the Angular tutorial: lesson text on the left with a step picker and Next, and a live workspace on the right. The lesson screens are interactive, so you can click through all five steps in 1b.
